PRIVACY POLICY

Information about how the current version of Star Swarm works.

Last updated: 20 October 2026

Current status: Advertising and donation checkouts are not enabled. This notice describes the current game code. It must be reviewed and updated before advertising, analytics or payment services are introduced.

Who operates Star Swarm?

Star Swarm is created by MrJim. For project-related questions you can open a GitHub Issue. Issues are public: do not include sensitive or personal information. A private contact channel and, where required, additional operator details must be established before monetisation.

Gameplay data

The game runs within your browser. It uses your score, current wave, lives and player controls locally to operate the game. The current game code does not create player accounts or upload scores to a remote leaderboard.

Local storage and cookies

The game saves your preferred soundtrack using the browser's localStorage with the key starswarm.soundtrack. This is a local preference, not an advertising identifier. You can change it in the game or remove it by clearing this site's stored data in your browser settings.

The current game does not install AdSense scripts or advertising cookies. Hosting providers and any third-party resources you access may process connection information as described below.

Hosting and external services

The website is deployed on GitHub Pages. GitHub may receive technical connection details (for example, network requests and IP address) to deliver the website. See the GitHub privacy statement.

Star Swarm includes a rare video easter egg for implausible game scores. If that event occurs, the page loads a YouTube embed from youtube-nocookie.com. The provider may receive browser and network information when the frame is loaded. Closing the overlay removes the frame. See Google's privacy policy.

Advertising and consent

There are currently no ads on the site and no advertising-consent panel to reopen. If Google AdSense is added in the future, this privacy notice will be updated to describe any relevant third-party tracking, purposes, vendor disclosures and user choices. A Google-certified consent management platform will be configured where required before ads are enabled. A normal information link is not itself a consent-management tool.

Donations and payments

Donations are not available in this version. Star Swarm does not ask you for payment card details. Any future payment service will be clearly identified and disclosed here before activation.

Updates

This notice will be updated if the game's data practices change. You can ask a public project-related question through the GitHub project, but please do not share private information there.
